Why this matters

This module is about thinking on purpose: noticing the assumptions and thought traps that get in your way, and using a simple tool, the 4C Check, to think more clearly.

The second half connects straight to your capstone. You'll write your first STAR(T) draft and use the same 4C Check to make it clearer, more honest, and more specific.

What you'll be able to do

By the end of this module:

  1. A

    Objective A: I can identify one thinking habit that sometimes gets in my way and name a strategy for interrupting it.

    You'll show this in Mile Marker #9
  2. B

    Objective B: I can apply the 4C Check (Clarity, Context, Credibility, Consequences) to evaluate a real situation or decision.

    You'll show this in the AI Chat: Think It Through
  3. C

    Objective C: I can explain the STAR(T) framework and describe how each of the five steps works.

    You'll show this in Mile Marker #9
  4. D

    Objective D: I can draft one practice STAR(T) response using a real experience and apply the 4C Check to strengthen it.

    You'll show this in Mile Marker #9
